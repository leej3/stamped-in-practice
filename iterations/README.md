# Research-skill trials

These datasets record completed attempts to improve research guidance through scientific work.
Start with the [trial history](../docs/trials.md) for what was done and why, or the [project lessons](../LESSONS.md) for what to change next.

- [Trial with failed results reporting](trial-with-failed-results-reporting/): the completed development trial that exposed problems in the initial experimental setup.
- [NARPS study runs](narps-study-runs/): the completed three-round comparison of four assistance strategies.

Each is a separate versioned dataset.
Its README introduces the outcomes and links to the detailed evidence.
Create a new, descriptively named dataset for a future comparison rather than restarting a completed trial.
