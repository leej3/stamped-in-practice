# NARPS gain-effect group analysis

This project tests positive group-level gain-effect estimates in the complete NARPS equal-indifference group using the supplied AO86 maps. Individual preprocessing and modeling are fixed inputs; no time-series data are used.

## Reproduce

From this directory, retrieve the annexed input payloads if needed, install the locked environment, and run:

```sh
git annex get input/data
pixi install
pixi run python analysis/run_analysis.py
```

The command rewrites the declared outputs under `results/` and `figures/`. The exact analysis protocol is in `protocol.md`; source meanings and checksums are in `input/sources.json`. `pixi.toml` and `pixi.lock` define the environment.

## Deliverables

- `report/report.md`: concise scientific interpretation and limitations.
- `analysis/run_analysis.py`: complete executable group analysis, QC, tables, maps, and figures.
- `results/summary.json`, participant QC and voxelwise results; unthresholded NIfTI group maps and permutation null.
- `figures/whole_brain_group.png` and `figures/peak_participant_effects.png`, generated by the script.

The primary test is one-sided sign-flip max-t family-wise error control over the shared nonzero finite brain support (5,000 Monte Carlo sign patterns). The secondary BH FDR results are exploratory context. A descriptive sphere centered at MNI (0, 44, -12) mm (15 mm radius) is used to summarize vmPFC; it does not determine the whole-brain hypothesis decision.
