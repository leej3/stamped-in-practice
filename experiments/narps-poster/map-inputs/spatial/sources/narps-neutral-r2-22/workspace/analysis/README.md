# Analysis files

- `analyze.py`: reproducible group analysis and figure generation.
- `report.md`: concise scientific report and interpretation.
- `results/summary.tsv`: principal statistics.
- `results/quality_checks.json`, `results/input_integrity.tsv`: cohort and input QC.
- `results/*.nii.gz`: group maps and atlas ROI/common mask.
- `results/vmPFC_proxy_participant_values.tsv`: participant-level descriptive ROI summaries.
- `figures/`: report figures.

See the report for the execution command, statistical model, inference assumptions, and limitations.
