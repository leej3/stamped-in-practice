# Observed skill activity

These records distinguish assigned assistance, available skills, discovery, installation, instruction loading and observed application.
They preserve failed attempts and exact native event citations; installation or reading alone is not evidence of benefit.
The coordinator has not used these records to grade scientific adequacy.

The [manifest](manifest.json) binds all 24 original records and their extraction scripts.
Original full transcripts and skill contents remain in experiment retention.
Event hashes in the first wave include the JSONL newline; later records exclude it.
The manifest identifies the verified convention without altering any original record.
